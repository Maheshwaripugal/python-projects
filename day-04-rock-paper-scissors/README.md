A simple command-line implementation of the classic **Rock, Paper, Scissors** game built using Python.

## 📖 Overview

This project allows a player to compete against the computer by choosing one of three options:

- 🪨 Rock
- 📄 Paper
- ✂️ Scissors

The computer randomly selects its move, and the program determines the winner based on the game rules.

---

## ✨ Features

- Interactive command-line gameplay
- Random computer move generation
- ASCII art representation of each choice
- Win, lose, and draw detection
- User-friendly prompts and output

---

## 🛠️ Concepts Practiced

- Variables
- User Input
- Conditional Statements (`if`, `elif`, `else`)
- Lists
- Random Module
- Basic Game Logic
- Control Flow
